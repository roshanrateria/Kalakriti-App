# Image Editing Test Project

This is a test project to try out Google GenAI's image editing capabilities using the Gemini API.

## Setup

1. Install dependencies:
   ```powershell
   npm install
   ```

2. Add a sample image:
   - Place a PNG image named `cat_image.png` in this directory
   - Or modify the `imagePath` in `test-image-editing.js` to point to your image

3. Run the test:
   ```powershell
   npm start
   ```

## What it does

The script will:
1. Read your input image (`cat_image.png`)
2. Send it to the Gemini 2.5 Flash Image model with a prompt to create a modified version
3. Save the generated image as `gemini-native-image.png`

## API Key

Set your API key as an environment variable:
```powershell
$env:GOOGLE_AI_API_KEY = "your-api-key-here"
```

## Files

- `test-image-editing.js` - Main script
- `package.json` - Project configuration
- `cat_image.png` - Input image (you need to provide this)
- `gemini-native-image.png` - Output image (generated by the script)
